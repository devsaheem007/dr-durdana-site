EMAIL CONTACT FORM
The contact form is prepared for Formspree but cannot be activated until a Formspree Form ID exists for the clinic. A static website cannot send an email directly from the browser without a mail/form service or backend.

TO ACTIVATE IT YOURSELF
1. Create a Formspree account and verify the clinic email.
2. Create a New Form.
3. Set the target email to aesthetik80@gmail.com in Formspree's form settings.
4. Copy the form endpoint / Form ID from the Integration section.
5. Open index.html.
6. Find: https://formspree.io/f/YOUR_FORM_ID
7. Replace YOUR_FORM_ID with the real ID.
8. Upload the updated website and test the form.

Formspree's current documentation confirms that a normal HTML form can use an endpoint such as https://formspree.io/f/{form_id} with method="post"; fields need name attributes. It also supports JavaScript/AJAX submissions with inline success/error states.

WHATSAPP AUTORESPONDER
The website cannot itself run a WhatsApp autoresponder. Configure the Greeting/Away messages in WhatsApp Business on the clinic's phone. The website handles the booking message; WhatsApp Business handles the automatic reply after the patient messages.
